# leads-panel — панель заявок (React + TypeScript)

Интерфейс менеджера: заявки из бота и сайта в одной таблице. Фильтры, поиск, сортировка, смена статуса, карточка с заметкой, сводка по деньгам, выгрузка в CSV. Данные демонстрационные, сохраняются в браузере (localStorage), сервер не нужен.

**Демо:** https://c17h24no4-sudo.github.io/leads-panel/

## Что показывает
- **React 19 + TypeScript** со строгими типами (`Status`, `Service`, `Lead`, `Filters`), хуки, `useReducer`, `useMemo`.
- Бизнес-логика вынесена в чистые функции (`src/logic.ts`): фильтрация, сортировка, статистика, CSV с экранированием. Их легко тестировать отдельно от интерфейса.
- Доступность: подписи у полей, `aria-pressed` у фильтров, управление с клавиатуры, светлая и тёмная тема, работает на телефоне.
- **12 тестов** (Vitest + Testing Library): логика, поиск, фильтры, смена статуса меняет сводку, заметка переживает перезагрузку. Проверено мутацией: если сломать формулу конверсии, тест падает.
- CI: проверка типов, тесты, сборка.

## Запуск
```
npm install
npm run dev     # разработка
npm test        # тесты
npm run build   # сборка в dist/
```

Это часть связки с чат-ботом заявок: бот собирает заявку и ориентировочную цену, панель показывает их менеджеру.
